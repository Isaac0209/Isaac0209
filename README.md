## 👨‍💻 Sobre mim

Sou desenvolvedor full-stack e trabalho com plataformas web de alto volume, onde disponibilidade e consistência de dados não são opcionais. Meu dia a dia vai da modelagem do banco e das APIs em Laravel até o frontend em Vue e os clusters Kubernetes que mantêm tudo no ar.

- 🔭 Construindo e operando sistemas em produção com tráfego real
- 💳 Experiência com fluxos financeiros: cash-in, cash-out, webhooks e conciliação
- 🧩 Curto entender como as coisas funcionam por dentro: engenharia reversa de protocolos e automação
- 🐧 Ambiente de trabalho: Linux, terminal e Docker

---

## 🛠️ O que eu faço

| Área | Detalhes |
|---|---|
| **Backend** | APIs REST e painéis administrativos com Laravel + Filament, filas, cache e jobs agendados |
| **Pagamentos** | Integração com gateways PIX: geração de cobrança, saques, webhooks idempotentes e conciliação |
| **Frontend** | SPAs em Vue 3 e React, componentes reutilizáveis e consumo de APIs |
| **Mobile** | Apps em Flutter integrados ao mesmo backend |
| **Infraestrutura** | Kubernetes com Traefik, replicação MySQL, Redis, Docker e nginx |
| **Automação** | Ferramentas em Node.js/Puppeteer e Python, engenharia reversa de protocolos |
